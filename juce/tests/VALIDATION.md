# Shared JUCE UI validation

## 0.4.0 — 2026-10-05

Configured with `-DJUCE_SOURCE_DIR` pointing at JUCE 7.0.12, Release, GCC 13.3,
run under Xvfb. `PianoRollViewChecks` passed **29 checks** using a minimal
`PianoRollHost` and the real `PianoRollView` mouse handlers (see the module
`VALIDATION.md` for the list). `PianoRollCommandUIChecks` passed its 195 checks
unchanged. Window focus and OS/DAW mouse or keyboard delivery are not validated
by these headless runs.


## 0.3.1 — current run, 2026-09-21

The standalone CMake harness compiled and linked against JUCE 7.0.12 on Linux
with GCC 13.3. It now takes its application version from the core project.
The headless run passed **195 explicit control/callback checks**, including:

- an unsaved macro survives switching to search and executing a command;
- both Save and Discard allow subsequent close, with no command replay;
- Escape obeys the same draft policy;
- Insert and all F1–F24 keys convert modifiers, record and resolve independently;
- command parameters use the public integer reader, including exponent notation.

Xvfb could not create listening sockets in this environment. The run directly
invoked real JUCE control callbacks without a desktop peer and logged focus
assertions at JUCE Component.cpp:2666. **Actual window focus and OS/DAW keyboard
delivery are not validated.** This is not a fully passing on-screen GUI run.
Rendered images were generated by the existing harness; no new visual-layout
claim is made. No Windows plugin was built or run in this module-only update.

## 0.3.0 — historical run

The standalone `CommandUITests.cpp` exercises real JUCE controls and gesture
callbacks using a transactional command host. The focused run passed 52 checks:

- search, no-match feedback, unavailable reason, Enter execution and retained parameters;
- shortcut capture, conflict cancellation, explicit replacement, default restoration and minimum-width layout;
- macro naming, parameterized steps, order changes, save, single-transaction run and binding;
- JSON reopen with bindings/macros/parameters, invalid-file preservation and recovery;
- transform corners, snapshot-based deltas, one commit per gesture, Escape rollback and time stretch.

A native component screenshot was inspected for layout. Product adapters own
their separate integration checks, source mappings and undo/export behavior.
No Windows/FL keyboard-focus or host-dialog test is implied by this native run.
